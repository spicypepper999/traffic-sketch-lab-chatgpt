TRAFFIC SKETCH LAB v0.7.0 - WINDOWS PORTABLE

Double-click TrafficSketchLab.exe.
Your default browser will open automatically, pointed at the local game.
No Node.js, Python, installer, internet connection or administrator access required.

Keep the black console window open while playing. Close it when finished.
TrafficSketchLab.exe runs a local web server bound ONLY to 127.0.0.1 (your PC).
It does not connect to an external server.

If the browser does not open, copy the localhost URL shown in the console
and paste it into your preferred browser.

If Windows displays a SmartScreen warning, this file is a self-compiled,
unsigned development prototype. For maximum transparency, the source archive
includes launcher/main.go; you can build the executable yourself.

Low-end PC performance tips:
  * Set Rendering to 'Fast - 1x resolution' (default).
  * Keep the browser window to a reasonable size.
  * Turn off the lane debug overlay when not editing.
  * Check browser graphics settings if Canvas2D runs in software rendering.
